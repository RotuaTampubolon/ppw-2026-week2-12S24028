Single Page Portfolio

Sistem Informasi Perpustakaan

Mata kuliah: Basis Data (12S3202) · Nilai: A-

Aplikasi Manajemen Tugas

Aplikasi manajemen tugas berbasis Java OOP, dibangun dengan pendekatan rekayasa perangkat lunak terstruktur mulai dari requirement, desain, hingga implementasi.

Mata kuliah: Rekayasa Perangkat Lunak (12S3303) · Nilai: A

Modernisasi Portofolio (Minggu 3)

Refactoring halaman portofolio Minggu 2 ke ekosistem Bootstrap 5.3: navbar responsif dengan hamburger toggle, hero section, grid kartu proyek dengan modal detail, dan formulir dengan floating labels serta validasi visual — dipadukan dengan custom CSS variables untuk menjaga identitas warna personal.

Mata kuliah: Pemrograman & Pengujian Web (12S3101) · Praktikum Minggu 3
